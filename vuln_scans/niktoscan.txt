========================================
 SUMMARY
========================================
1. Missing Security Headers
   - X-Frame-Options not present (clickjacking exposure)
   - X-Content-Type-Options not present (MIME-sniffing exposure)

2. Dangerous HTTP Methods Enabled
   - Allow header advertises PUT and DELETE in addition to
     GET, HEAD, POST, OPTIONS
   - PUT could allow file upload/overwrite on the server
   - DELETE could allow removal of server-side resources
   - The risk depends on whether these methods are properly access
     controlled at the application layer (further testing required
     to confirm exploitability)

Note: Nikto's HTTP method findings are indicative, not conclusive.
Confirmed via manual OPTIONS request above; further manual testing
    (e.g. attempting actual PUT/DELETE requests) is recommended.
